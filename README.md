# LanguageFileEditor

## Hinweis zur Auto-Übersetzung (DE)

Die Auto-Übersetzungsfunktion verwendet externe Übersetzungsdienste (z. B. LibreTranslate-Endpunkte und ggf. MyMemory als Fallback).

- Übersetzungstexte werden dabei an den jeweiligen externen Dienst übertragen.
- Bitte **keine vertraulichen oder personenbezogenen Inhalte** automatisch übersetzen lassen, wenn du öffentliche Endpunkte nutzt.
- Prüfe die Nutzungsbedingungen und Limits des verwendeten Endpunkts.

Empfehlung für mehr Kontrolle: Eigene (self-hosted) LibreTranslate-Instanz verwenden.

**Nutzungsrahmen:** Diese Anwendung ist für die **private, nicht-kommerzielle Nutzung** gedacht.

---

## Auto-Translation Notice (EN)

The auto-translation feature uses external translation services (e.g., LibreTranslate endpoints and optionally MyMemory as a fallback).

- Translation texts are sent to the selected external service.
- Please **do not auto-translate confidential or personal content** when using public endpoints.
- Check the endpoint’s terms of use and rate limits.

Recommended for better control: Use your own self-hosted LibreTranslate instance.

**Usage scope:** This application is intended for **private, non-commercial use**.
