# Hytale Translation Helper (Electron Port)

## Start

```bash
npm install
npm start
```

## Implemented features

- Languages folder selection
- `.lang` file selection
- Tree/list key navigation
- Side-by-side multi-language editors
- Search/filter + only missing
- Next missing key navigation
- Save all languages to disk
- Create language (optional fallback)
- JSON import/export
- Auto-translation (LibreTranslate endpoints)
- DE/EN UI switch
- State persistence to `config/lfe.config` next to EXE

## Notes

This is the Electron migration baseline in plain JS/HTML/CSS.
